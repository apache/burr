.. _s3-artifacts-integration:

===================
S3 Artifact Storage
===================

An :py:class:`ArtifactStore <burr.core.artifacts.ArtifactStore>` backed by an
`AWS S3 <https://aws.amazon.com/s3/>`_ bucket. See :doc:`../../concepts/artifact-storage` for
background on artifact storage in general.

Install the optional extra (pulls ``boto3``):

.. code-block:: bash

   pip install "apache-burr[s3]"

-------------
Quick Example
-------------

.. code-block:: python

    from burr.core import ApplicationBuilder
    from burr.integrations.artifacts.s3 import S3ArtifactStore

    object_store = S3ArtifactStore.from_values(
        bucket="my-bucket",
        prefix="burr-artifacts",  # optional
    )

    app = (
        ApplicationBuilder()
        .with_actions(...)
        .with_transitions(...)
        .with_state(...)
        .with_entrypoint(...)
        .with_object_store(object_store)
        .build()
    )

If you already have a boto3 client (e.g. reusing a connection, custom endpoint for testing with
`moto <https://github.com/getmoto/moto>`_ or a local S3-compatible server), construct the store
directly and pass it in:

.. code-block:: python

    import boto3
    from burr.integrations.artifacts.s3 import S3ArtifactStore

    client = boto3.client("s3", region_name="us-east-1")
    object_store = S3ArtifactStore(bucket="my-bucket", prefix="burr-artifacts", client=client)

---------------
IAM Permissions
---------------

At minimum, the runtime identity used by Burr needs permission to read/write/check objects in
the target bucket (optionally scoped to the configured prefix):

* ``s3:PutObject``
* ``s3:GetObject``
* ``s3:HeadObject``
